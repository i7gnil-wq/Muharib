# مُحارِب

منصة للنصر في حرب الإدمان عن طريق تدريبات ومتابعات.

## هيكل الملفات

```
muharib/
├── index.html        ← واجهة تسجيل الدخول (الصفحة الرئيسية)
├── warrior.html      ← الواجهة الداخلية (فارغة حالياً)
├── css/
│   └── style.css     ← التنسيق (الأحمر، الرمادي، البيج)
└── js/
    ├── storage.js    ← حفظ بيانات المحاربين وتوليد الكود
    ├── login.js      ← منطق صفحة تسجيل الدخول
    └── guard.js      ← يعيد غير المسجّلين إلى صفحة الدخول
```

## النشر على GitHub Pages

1. ارفع محتويات المجلد كلها (مع الحفاظ على المجلدين `css` و`js`) إلى مستودع جديد.
2. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط الذي يظهر، وسيعمل الموقع مباشرة.

كل الروابط بين الملفات نسبية، لذلك تعمل سواء كان الموقع على نطاق خاص أو داخل مسار المستودع.

## ملاحظة مهمة

البيانات تُحفظ في `localStorage` داخل متصفح المستخدم، لأن GitHub Pages لا يدعم خادماً.
لذلك يعمل كود «المحارب القديم» على نفس المتصفح والجهاز الذي سُجّل منه فقط.
لدعم الدخول من أي جهاز يلزم لاحقاً ربط الموقع بقاعدة بيانات (مثل Firebase أو Supabase).
